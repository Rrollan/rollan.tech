# Руки для остановки

Генерация: Tripo Studio, H3.1, 2026-10-20.
Task: `2ad9bf68-3691-4625-a192-205796e15136`.
Стоимость генерации: 55 кредитов; ретопология: 5. Баланс до: 1460, после: 1400.

Исходник: 1 985 552 треугольника. Для браузера: 20 000 треугольников,
2K PBR-текстуры WebP, GLB 2 130 428 байт. Загрузка одна для двух рук.
Файл: `assets/models/web/hand.glb`; риг: `src/native-hand.js`.
У каждой руки 22 кости; пальцы и запястье двигаются при захвате и возврате.
Во время чтения слой рук не перерисовывается до изменения размера окна.

Направление: фактурная рука с естественной анатомией и единым рукавом
в той же тёплой, обжитой эстетике, что бетон, дерево и бумага остановки.
Исходная модель — левая; правая отражается из неё для одинаковой фактуры.
Риг, захват, перенос листка и возврат на стену настраиваются в приложении.
