# rollan.tech

Личная сайт-визитка — доска объявлений на грязной остановке, вид от первого лица.
Клик по объявлению открывает раздел.

Деплой: статика на Vercel из ветки `main`. Свой домен `rollan.tech` привязан в панели Vercel.

## Памятка для агентов

- `index.html` — единственный файл сайта (одностраничник ~1.7 МБ, картинки и стили заинлайнены).
  Правь его напрямую, аккуратно: файл большой, не перегенерируй целиком без нужды.
- Файл изначально экспортирован из артефакта «Сайт-визитка» в Muse — но источник правды
  теперь этот репозиторий, а не артефакт. Правки через артефакт затрут изменения из репозитория.
- Каждый пуш в `main` автоматически деплоится на Vercel в прод. Для экспериментов —
  отдельная ветка или PR: Vercel выдаст превью-ссылку, прод не тронется.
- Шрифты: Google Fonts (Russo One — заголовки, Caveat — рукописные пометки, Inter — текст).
- Контакты на сайте: Telegram @oderefyu, GitHub Rrollan.

## Новая 3D-версия (превью)

Исходный `index.html` сохранён. Новая версия открывается по `/scene.html`.

```sh
npm ci
npm run dev
```

Открыть `http://127.0.0.1:4173/scene.html`.

- `npm test` — конфиг, ссылки, движение, перерисовка при жесте, пропорции города опора на геометрию лавки и риг рук.
- `npm run build` — обе страницы и модели в `dist/`.
- `npm run preview` — локальная проверка собранной версии.
- `public/scene-config.json` — тексты объявлений, ссылки, расположение и свет.
- `src/main.js` — взаимодействие со сценой и чтение объявлений.
- `src/paper.js` — единый печатный макет для стены, подъёма и чтения.
- `src/reader.js` — захват, чтение и возврат листа.
- `src/companion.js` — поглаживание кота, реакция меша и тихое мурчание.
- `src/hands.js`, `src/native-hand.js` — отдельный WebGL-слой рук Tripo и риг пальцев.
- `src/navigation.js` — прогулка, жесты и приближение камеры.
- `src/world.js` — окружение, свет, модели и опора предметов.
- `src/flyers.js` — бумага на стенах и отклик на наведение.
- `assets/environment/` — нарисованная вечерняя панорама города.
- `assets/models/web/` — скачанные из Tripo и сжатые GLB.
- `docs/ASSET_LEDGER.json` — происхождение моделей и затраченные кредиты.

### Управление и содержимое

Потянуть сцену — оглядеться. Нажать на пол — подойти. WASD — ходить,
стрелки — идти и поворачиваться. Нажать на листок — приблизиться, взять его 3D-руками и прочитать.
Один canvas-макет используется во всех состояниях; полное содержимое прокручивается
внутри листа, ссылки остаются нативными HTML-ссылками. Большие пальцы лежат
на лицевой стороне, остальные пальцы скрываются за краями.
Нажать на кота — присесть, погладить и вернуться. Escape отменяет действие.
В начале на 10 секунд появляется подсказка о ходьбе.
Крестик или Escape возвращают на прежнее место. С клавиатуры объявления доступны
через Tab. Системное уменьшение анимации учитывается.

На телефоне: жест для взгляда, касание пола для движения. Дополнительно движение
можно вести пальцем из нижнего левого угла; второй палец одновременно управляет взглядом.
Постоянных панелей и публичных настроек нет. Старые локальные черновики игнорируются.

Пока содержимое меняется в `public/scene-config.json` через репозиторий.
Отдельный закрытый кабинет с настройками и статистикой — следующий этап;
авторизация, хранение и сбор статистики сейчас не реализованы.

### Модели

Три модели Tripo: остановка, жилой дом и спящий кот. Они упрощены до 80k, 18k
и 14k треугольников и экспортированы в GLB с текстурами 2K/1K. Локальное сжатие
текстур в WebP уменьшило суммарный размер до примерно 6.2 МБ. Исходные экспорты
сохранены локально в игнорируемой папке `assets/models/source/`; они не входят
в деплой. `scripts/compress-models.mjs` воспроизводит сжатие из этих исходников.
Текущая сцена загружает остановку, кота и новую руку: дом заменён панорамой.
Исходная панорама сохранена; в сцене используется её прозрачный силуэт с отдельным небом. Три загружаемые GLB суммарно 6.89 МБ.
Рука с рукавом отдельно сгенерирована в Tripo, упрощена с 2M до 20k треугольников
и сжата до 2.13 МБ с PBR-текстурами 2K WebP. Один меш отражается для второй руки,
у каждой 22 кости. Промпт и расходы: `docs/TRIPO_HANDS.md`. Бутылки и бумага созданы
геометрией и canvas-текстурами. Промпт панорамы: `docs/ART_DIRECTION.md`.

### Публикация

`vercel.json` задаёт сборку Vite и папку `dist`. Новую сцену нужно сначала
проверить в Vercel Preview на `/scene.html`. Для переноса её на главную страницу
нужен отдельный финальный шаг после визуальной проверки. Текущий `index.html`
по-прежнему показывает прежнюю визитку.

Визуальные итерации проверять локально через `npm run dev`; отправлять в Vercel
один проверенный набор изменений, чтобы беречь лимиты деплоев и сборки.
